# AIP 如何保证安全？

## 问题

AI 生成的指令会不会有安全风险？

## 解答

AIP 内置了多层安全机制：

1. **workspace 隔离**: 所有文件操作指令严格限定在配置的 workspace 目录内，无法越权访问系统其他路径
2. **指令白名单**: 通过 SetAllowedCommands 可以精确控制 AI 只能执行哪些指令
3. **事务追踪**: 每条指令都有唯一 id，可追溯、可审计
4. **超时控制**: 所有指令都有默认超时时间，防止失控

## 示例

```atp
terminal#t1:rm -rf /
```

如果 workspace 配置为 `/home/sa/dev/`，这条指令的操作范围会被限定在该目录内，无法影响系统其他路径。
