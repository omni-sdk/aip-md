# 每一次操作都可回放、可追溯、可审计

> AIP 指令是文本，文本就是记录。
> 一条指令生成、执行、返回，全过程天然被写入日志。
> AI 的行为第一次变得可解释、可复现。

---

## 场景：三个月后的审计

有人问："三个月前，谁改过生产环境的配置文件？"

翻出 AIP 日志：

```text
id:cfg_001
code:20
time:2026-06-15T14:23:11+08:00
text:success
data:./prod/config/app.yaml

id:cfg_002
code:20
time:2026-06-15T14:23:12+08:00
text:success
data:./prod/config/db.yaml

id:cfg_003
code:52
time:2026-06-15T14:23:14+08:00
text:execute: command failed: exit status 1
data:permission denied
```

三条记录，精确到毫秒。谁、什么时候、做了什么、成功还是失败，一目了然。

---

## 场景：回放指令，复现当时状态

不只是审计，还可以**回放**：

```atp
run#replay:./logs/2026-06-15.cmd
```

把三个月前的指令重新跑一遍，看看能不能复现当时的系统状态。如果能复现，说明系统变化是可追踪的；如果不能，就说明中间有人做了没有被记录的操作。

---

## 为什么这很独特

- JSON 日志只记录"结果"，AIP 记录的是"**过程**"
- 每一条指令都有 `#id`、`code`、`time`、`data`，天然具备审计要素
- 这对生产级 Agent 系统是刚需：AI 的行为必须有据可查、有迹可循
- 可以写测试用例、可以做合规检查、可以做故障回溯
