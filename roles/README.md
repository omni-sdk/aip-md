# AITP 角色示例

本目录包含不同角色使用 AITP 指令的示例。每个文件描述了一个典型角色及其常用指令集。将这些角色描述复制到 AI 的系统提示中，AI 即可模拟该角色的行为。

## 角色列表

| 角色文件 | 角色描述 |
|---------|---------|
| role-system-admin.md | 系统管理员 — 服务器监控、备份、故障排查 |
| role-devops.md | DevOps 工程师 — CI/CD、容器、批量部署 |
| role-data-scientist.md | 数据科学家 — 模型训练、数据处理 |
| role-home-automation.md | 家庭自动化管理员 — 智能家居联动 |
| role-iot-developer.md | 物联网开发者 — 嵌入式设备控制 |
| role-backend-dev.md | 后端开发者 — API、数据库、日志 |
| role-frontend-dev.md | 前端开发者 — 构建、打包、部署 |
| role-security-engineer.md | 安全工程师 — 安全审计、入侵检测 |

## 如何使用

1. 打开任意角色文件，查看该角色的典型 AITP 指令
2. 将角色文件内容复制到 AI 的系统提示中，AI 即可模拟该角色的行为
3. 指令以 `atp` 代码块标注，返回结果以 `json` 代码块标注
